## ✨ Visual Features

- **Custom glowing bullets** (capsule shape + trail)
- **Particle explosions** (circles, sparks, squares)
- **Ship motion blur / after-images**
- **Animated energy shields** on hit
- **Strong screen shake** when damaged
- Twinkling starfield overlay
- Engine glow behind ships
- Neon center border
- Modern glowing health bars
- Pulsing main menu title

---

## 🕹️ Controls

| Player            | Movement        | Shoot       |
|-------------------|-----------------|-------------|
| **Yellow** (Left) | `W A S D`       | `Left Ctrl` |
| **Red** (Right)   | Arrow Keys      | `Right Ctrl`|

- Max 3 bullets per player  
- `SPACE` = Start · `R` = Restart · `ESC` = Quit
